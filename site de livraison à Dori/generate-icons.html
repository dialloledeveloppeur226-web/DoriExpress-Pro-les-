📦 Générateur d'icônes DoriExpress-Pro

Cliquez sur le bouton ci-dessous pour générer toutes les icônes de l'application.

📋 Instructions :
1. Cliquez sur "Générer les icônes"
2. Faites un clic droit sur chaque icône → "Enregistrer l'image sous..."
3. Placez les fichiers dans le dossier assets/icons/
4. Pour les logos, utilisez la même méthode
✅ Alternative :
Pour des icônes professionnelles, utilisez :
- favicon.io (générateur de favicon)
- Flaticon (icônes prêtes à l'emploi)
- Figma (création personnalisée)
